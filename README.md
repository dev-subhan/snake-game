# 🐍 Snake Game

A classic Snake Game built from scratch using vanilla HTML, CSS and JavaScript — no frameworks or libraries.

## 🎮 Play Live
👉 [Click here to play](https://dev-subhan.github.io/snake-game)

## ✨ Features
- Cyberpunk neon & Retro arcade themes
- Score, high score & timer tracking
- Speed selection — Slow / Medium / High
- Mobile d-pad controls
- High score saved in local storage

## 🛠️ Built With
- HTML
- CSS
- JavaScript
